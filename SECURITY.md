# Security reporting

Do not report vulnerabilities by publishing account data, Cookies, tokens, logs, or screenshots in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Include the affected version and a concise reproduction without real user credentials.

Operators must keep panel environment files, account databases, session keys, Web Push keys, Cookies, logs, APK signing keys, and signing passwords outside Git. Rotate credentials immediately if one is exposed. Verify release hashes before installing the provided binaries.
